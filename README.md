# MediConnect CRM - Salesforce Project

## Overview
MediConnect CRM is a custom Salesforce-based Hospital Management System designed to manage patient records, doctor details, appointments, treatments, and billing processes.

## Features
- Patient Management
- Doctor Management
- Appointment Scheduling
- Treatment Tracking
- Billing & Payment Records
- Reports & Dashboards
- Automated Flows

## Technologies Used
- Salesforce CRM
- Apex
- Salesforce Flows
- Custom Objects
- Validation Rules
- Reports & Dashboards

## Data Model
Objects used:
- Patient__c
- Doctor__c
- Appointment__c
- Treatment__c
- Billing__c

## Automation
- Appointment booking flow
- Billing calculation automation
- Validation rules for data accuracy

## Future Improvements
- Patient Portal
- LWC Appointment Scheduler
- SMS Notifications
